        걸린 항목과 검토 기록 원문 확인 후 판단을 남긴 감사 추적

          파이프라인 수정 이력 검증과 테스트가 찾아낸 내 코드의 오류

          작동 방식

          1. 수집DART Open API로 정기·감사보고서 원문을 받아 모든 표를 셀 단위로 저장
          2. 추출원문 표에서 CSM 열을 찾아 변동표를 자동 추출하고, 금감원 잔액과 맞는 표 조합을 자동 선택
          3. 검증규칙 6개를 회사·연도마다 자동 실행해 불일치·확인 필요 항목 표시
          4. 검토 기록걸린 항목마다 원문을 확인하고 판단과 근거를 남김
          5. 요약·대조요약 문장(또는 AI 설명) 속 숫자를 원표와 자동 대조한 뒤 화면에 표시
          R1 변동표 항등식 기초+신계약+상각+이자부리+조정 = 기말
          R2 금감원 잔액 대조 DART 기말 CSM = FISIS 잔액
          R3 연속성 당기 기초 = 전기 기말
          R4 포트폴리오 합계 포트폴리오 합 = 공시 합계(예상보험금 표)
          R5 급변 탐지 위험보험료 ±50% 이상, 상쇄율 업계 강건 z ≥ 3
          R6 기준 변경 문구 주석의 '제외하여 작성·제도변경·재작성' 등 탐지
