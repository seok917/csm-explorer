# CSM 공시 탐색기

생명보험사 22곳의 IFRS17 보험계약마진(CSM) 공시를 자동으로 수집·정리·검증해,
**회사명을 검색하면 지표·변동 분해·검증 결과가 바로 나오는 웹페이지**로 보여주는 개인 프로젝트입니다.

> 공시자료 기반 개인 분석이며 각 보험회사의 공식 자료가 아닙니다.

## 무엇을 보여주나
- **핵심 지표**: 기말 CSM·순증률, 신계약 CSM, 조정 추정치 변동(신계약 대비 비율), IFRS17 전환일 이후 인식 계약 비중, 업계 순위
- **CSM 변동 분해**: 기초 → 신계약 → 이자부리 → 상각 → 조정 추정치 → 기말 (폭포 차트)
- **자동 요약**: 원표 숫자를 규칙 기반 문장에 자동 대입해 변동 원인을 설명
- **자동 검증**: 규칙 6개를 회사·연도마다 실행해 통과 / 불일치 / 확인 필요 표시
- **가정과 실제**: 보험금 예실차비율, 연말 미래 예상손해율(위험보험료 대비 예상보험금)
- **업계 비교**: 22개사 중 위치 (기말 CSM·신계약 CSM·조정 비율·전환일 이후 비중)
- **기준 변경 신호**: 공시 원문에서 '제외하여 작성·제도변경·재작성' 등 문구 자동 탐지

## 작동 방식
1. **수집**: DART Open API로 정기·감사보고서 109건(22개사, 2023~2026 상반기)의 원문을 받아 모든 표를 셀 단위로 저장 (`17_dart_all_tables.R`)
2. **추출**: 회사마다 다른 표 양식(행 형식·XBRL 형식·분할 표)을 처리 규칙으로 표준 항목에 맞춤
3. **검증**: `pipeline/validate.py` — 규칙 6개 자동 실행
4. **화면**: `pipeline/export_web.py`(지표·요약 문장) → `pipeline/build_site.py`(웹페이지)

`python pipeline/run_all.py` 한 번으로 정리 → 원문 신호 탐지 → 검증 → 요약 → 페이지 생성까지 실행됩니다.
(정리된 데이터 기준 전체 약 10초. 1단계 원문 다운로드는 별도 R 스크립트)

## 검증 규칙
| 규칙 | 내용 |
|---|---|
| R1 변동표 항등식 | 기초 + 신계약 + 상각 + 이자부리 + 조정 = 기말 (허용오차 1억 원 또는 0.1%) |
| R2 금감원 잔액 대조 | DART 기말 CSM = 금감원 FISIS 잔액 |
| R3 연속성 | 당기 기초 = 전기 기말 |
| R4 포트폴리오 합계 | 포트폴리오별 예상보험금 합 = 공시 합계 (0.5% 이내) |
| R5 급변 탐지 | 1년차 위험보험료 전년 대비 ±50% 이상 / 신계약 대비 조정 비율이 업계 분포에서 강건 z ≥ 3 |
| R6 기준 변경 문구 | 주석의 산출 기준 변경·소급재작성 문구 탐지 |

**현재 결과**: 검증 348건 — 통과 273, 불일치 14, 확인 필요 28, 자료 없음 33.
불일치·확인 필요 항목은 원문을 확인해 원인을 기록했습니다. 예: 합병 효과로 인한 변동표 잔차,
금감원 통계와 주석의 CSM 범위 차이, 예상보험금 산출 기준 변경(종신연금지급금 제외), 과거 재무제표 소급재작성.

## 폴더
```
index.html          완성된 웹페이지 (GitHub Pages가 바로 보여줌)
data/               표준화된 데이터(CSV)와 화면용 web.json, 검증 결과 checks.csv
pipeline/           정리·탐지·검증·요약·페이지 생성 스크립트
site/template.html  화면 템플릿
```
