# CSM 공시 탐색기

[![테스트](https://github.com/seok917/csm-explorer/actions/workflows/tests.yml/badge.svg)](https://github.com/seok917/csm-explorer/actions/workflows/tests.yml)

생명보험사 22곳의 IFRS17 보험계약마진(CSM) 공시를 자동으로 수집·정리·검증해,
**회사명을 검색하면 지표·변동 분해·검증 결과가 바로 나오는 웹페이지**로 보여주는 개인 프로젝트입니다.

> 공시자료 기반 개인 분석이며 각 보험회사의 공식 자료가 아닙니다.

## 무엇을 보여주나
- **핵심 지표**: 기말 CSM·순증률, 신계약 CSM, 조정 추정치 변동(신계약 대비 비율), 전환일 이후 계약 비중(수정소급·공정가치법 외 계약), 업계 순위
- **CSM 변동 분해**: 기초 → 신계약 → 이자부리 → 상각 → 조정 추정치 → 기말 (폭포 차트)
- **자동 요약 + 숫자 대조**: 원표 숫자를 규칙 기반 문장에 자동 대입하고, 문장 속 숫자를 원표와 다시 대조(가드레일)
- **AI 설명(선택)**: API 키가 있으면 AI가 변동 원인을 설명하고, 같은 가드레일로 숫자를 대조해 틀리면 한 번 고쳐 쓰게 한 뒤 그래도 틀리면 반려
- **자동 검증**: 규칙 6개를 회사·연도마다 실행해 통과 / 불일치 / 확인 필요 표시
- **검증 현황 탭**: 22개사 × 규칙 매트릭스, 걸린 항목마다 원문 확인 후 남긴 판단·근거(감사 추적), 파이프라인 수정 이력
- **가정과 실제**: 보험금 예실차비율, 연말 미래 예상손해율(위험보험료 대비 예상보험금)
- **업계 비교**: 22개사 중 위치 (기말 CSM·신계약 CSM·조정 비율·전환일 이후 비중)
- **기준 변경 신호**: 공시 원문에서 '제외하여 작성·제도변경·재작성' 등 문구 자동 탐지

## 작동 방식
1. **수집**: DART Open API로 정기·감사보고서 109건(22개사, 2023~2026 상반기)의 원문을 받아 모든 표를 셀 단위로 저장 (처음엔 R `17_dart_all_tables.R`, 이후 새 공시는 Python `pipeline/collect_dart.py`가 자동 수집)
2. **추출**: `pipeline/extract_movement.py` — 원문 표에서 CSM 변동표를 자동 추출하고 금감원 잔액으로 맞는 표를 자동 선택 (아래 설명)
3. **검증**: `pipeline/validate.py` — 규칙 6개 자동 실행 + `data/review_notes.csv`(사람의 검토 판단) 결합
4. **요약·대조**: `pipeline/export_web.py`(지표·요약 문장) + `pipeline/guard.py`(숫자 가드레일)
5. **AI 설명(선택)**: `pipeline/ai_explain.py` — 환경변수 `ANTHROPIC_API_KEY`가 있을 때만 실행
6. **화면**: `pipeline/build_site.py`(웹페이지)

`python pipeline/run_all.py` 한 번으로 원문 표 추출 → 원문 신호 탐지 → 검증 → 요약 → 페이지 생성까지 실행됩니다.
(저장소 스냅숏 `raw/csm_tables.csv.gz`만으로 전체 약 8초, 원문 전체 덤프(109개 보고서)로 실행하면 약 25초. 원문 다운로드는 별도 R 스크립트)

```bash
python pipeline/run_all.py                           # 전체 실행
ANTHROPIC_API_KEY=sk-... python pipeline/run_all.py  # AI 설명까지 (키는 코드·저장소에 넣지 말 것)
python tests/test_pipeline.py                        # 자동 테스트 25개
```

## 원문 표 자동 추출 (`pipeline/extract_movement.py`)
보험사마다 변동표 양식이 다릅니다. 전환방법별 열(수정소급·공정가치·그 밖의 계약)과 소계 열 유무, 포트폴리오·유배당/무배당별 분할 표,
연결·별도 반복, 단위(백만원·천원·원), 행 이름(‘CSM 상각’ / ‘서비스를 제공한 보험계약마진’ / ‘당기인식분’ …)이 제각각입니다.

1. **CSM 열 찾기** — ① ‘CSM 상각’ 행: 상각은 CSM 열과 합계 열에만 숫자가 있어 어느 양식이든 CSM 열 위치가 드러남
   ② 머리글 구조: [현재가치, 위험조정, CSM(전환방법별), 합계]가 포트폴리오 수만큼 반복되는지 항등식으로 확인 ③ CSM만 전환방법별로 나눈 표
2. **항목 읽기** — 기초·신계약·상각·이자부리·조정 추정치 변동·기말 + 전환방법 외 계약의 기말·조정.
   기초·기말은 순부채(부채 + 자산 쪽 계약) 행을 우선(자산 쪽 계약에도 CSM이 있음)
3. **표 조합 선택** — 한 보고서의 후보 표 조합 × 단위 × 기초·기말 행 중 **금감원 FISIS 잔액과 가장 가까운 조합**을 자동 선택
4. **대조와 보정** — 자동값을 수작업 판독값(`data/movement_manual.csv`)과 항목별 대조(`data/extract_report.csv`).
   자동이 틀리는 경우만 사유를 적어 `data/overrides.csv`에서 수작업 값으로 대체

| 결과 (72개 회사·기간) | 건수 |
|---|---|
| 자동 추출 성공 | 71 |
| 수작업 판독값과 일치 (그중 27건은 수작업에 없던 전환방법별 값까지 추가 확보) | 66 |
| 자동값이 맞고 **수작업 판독값이 틀렸던 건** (유배당 표 누락 — 금감원 잔액·전기 기말과 0.1억 이내 일치로 확인) | 3 |
| 보정 파일로 처리 (금감원 통계 집계 범위 차이 2, XBRL 렌더링 표 열 정렬 깨짐 1) | 3 |

## 미래 이익 체력 (상각 예정표 · 상각률 · 대체율 · FISIS)
| 지표 | 계산 | 출처 |
|---|---|---|
| 상각률 | 상각 ÷ (기초+신계약+이자부리+조정) | 변동표 |
| 신계약 대체율 | 신계약 CSM ÷ 상각 (1배 초과 = 풀린 이익보다 많이 새로 쌓음) | 변동표 |
| CSM 상각 예정표 | 기말 CSM을 1년 이내 / 1~2 / 2~5 / 5~10 / 10년 초과로 나눈 비중, 절반 인식 시점 | DART 주석 (`pipeline/extract_schedule.py`) |
| 조정 = 가정 변경 + 경험 차이 | 해지율·위험률·사업비·기타 가정 변경 vs 물량차이·투자요소 예실차 | 요인별 분해 |
| 지급여력비율, 13·25회차 유지율 | 그대로 | FISIS 오픈API (`pipeline/collect_fisis.py`) |
| 신계약 CSM 배수 | 신계약 CSM ÷ 개인 보장성 초회보험료 (회사 안 추이로만 해석) | 변동표 + FISIS |

**상각 예정표 추출**: 원문의 연도 구간 표를 모두 읽고, 합계가 그 회사의 어느 시점 기말 CSM과 맞는지로 기준일을 정함(당기·전기 표 구분, 재보험·위험보험료 표 자동 제외). 병합 셀, 가로로 쪼개진 표(1~8년 / 9년~), 현재가치 합계 열, 할인 전 금액 공시를 처리. 22개사 모두 1개 시점 이상 확보.

**믿을 만한 지표인가** (`data/schedule_summary.json`, 자동 계산)
- 안정성: 같은 기준으로 공시한 16개사의 2024→2025 '1년 이내 비중' 변화 중앙값 0.2%p
- 변별력: 2025년 말 1년 이내 비중 3%(DB생명)~16%(BNP카디프생명), 10년 초과 비중 38~79%
- 순위 예측: 2024년 말 1년 이내 비중과 2025년 실제 상각률의 순위 상관 0.63 (16개사)
- 금액 예측은 불가: 다음 해 실제 상각 = 예정 '1년 이내'의 1.13배(2023.12), 1.64배(2024.12) (신계약·이자부리 미포함)
- 기준 변경: IBK연금, 동양생명, 신한라이프, 처브라이프는 2023년 말 예정표를 2024년 보고서에서 다른 값으로 재공시 → 2023과 2024 이후를 바로 잇지 않음

- 형식 통일: 한 보고서에 형식이 다른 예정표가 둘 있는 회사(교보 등)는 회사마다 한 형식으로 통일해 가짜 변동을 막음

## 가정 민감도 (`pipeline/extract_sensitivity.py`)
감독기관 표준 충격(사망률 3.27%·장해질병 3.40%·해지율 ±9.16%·사업비 2.62%)에서 CSM이 얼마나 변하는지. 변동 후 금액형(신한·라이나)·변동 금액형(교보·한화)·유배당/무배당 구분형(농협·DB)·재보험 전후 쌍(메트)·포트폴리오별 분리 표(신한 2025, 합산)를 같은 규칙으로 읽고, 기준 CSM이 그 회사 기말 CSM과 맞는 표만 채택. 15개사.

## 데이터 무결성 (독립 검토 후 추가한 자동 가드)
- 회사 섞임 방지: FISIS 회사코드 22곳 고정 대조, 변동표·예정표·FISIS·민감도 숫자 묶음이 두 회사에 동시에 나타나면 실패
- 시점 섞임 방지: 예정표·민감도 기준일은 그 보고서의 당기·전기 연말만 허용, 1·3분기는 화면 기간으로 쓰지 않음
- 근거 없는 추출 보류: 전년 기말(기초 기준)이 없는 새 기간은 화면에 올리지 않고 `data/held_periods.csv`에 기록
- 늦게 낸 공시도 수집: 회사·기간별로 없는 연간 보고서를 받음(감사보고서 4월 제출 회사 누락 방지)
- 정정공시: 대체된 옛 보고서의 표는 버림 · FISIS 일부 실패 시 지난 값 유지(빈칸으로 덮어쓰지 않음)
- 이 테스트가 하나라도 실패하면 주간 자동 업데이트는 결과를 커밋하지 않음

## 검증 규칙
| 규칙 | 내용 |
|---|---|
| R1 변동표 항등식 | 기초 + 신계약 + 상각 + 이자부리 + 조정 = 기말 (허용오차 1억 원 또는 0.1%) |
| R2 금감원 잔액 대조 | DART 기말 CSM = 금감원 FISIS 잔액 |
| R3 연속성 | 당기 기초 = 전기 기말 |
| R4 포트폴리오 합계 | 포트폴리오별 예상보험금 합 = 공시 합계 (0.5% 이내) |
| R5 급변 탐지 | 1년차 위험보험료 전년 대비 ±50% 이상 / 신계약 대비 조정 비율이 업계 분포에서 강건 z ≥ 3 |
| R6 기준 변경 문구 | 주석의 산출 기준 변경·소급재작성 문구 탐지 |

**현재 결과**: 검증 348건 — 통과 279, 불일치 8, 확인 필요 27, 자료 없음 34.
(원문 재추출 전: 통과 266, 불일치 14, 자료 없음 41 — 수작업 오류 수정으로 불일치 6건, 원문 행 확보로 자료 없음 7건 해소)
걸린 35건은 모두 원문을 확인해 판단과 근거를 `data/review_notes.csv`에 기록했습니다(원인 확인·추정·소액 차이·추가 확인 필요 등).
예: 합병으로 인한 변동표 잔차, 부채·자산 측 CSM 분리 공시와 환율변동효과, 금감원 통계와 주석의 집계 범위 차이,
예상보험금 산출 기준 변경(종신연금지급금 제외), 과거 재무제표 소급재작성. 원인을 특정하지 못한 2건은 '추가 확인 필요'로 남겨 두었습니다.

## 한계
- 공시 기준(별도·원수·공시 시점)이라 회사 내부 관리 수치와 다를 수 있음
- 요약 문장은 숫자를 자동 대입한 서술이며 원인을 단정하지 않음
- 숫자 가드레일은 숫자가 원표에 있는지만 확인하며, 문장의 해석이 맞는지는 사람이 판단해야 함
- AI 설명 기능은 API 키가 있어야 작동하며, 실제 API 호출 경로는 키 없이 테스트할 수 없어 가짜 응답으로만 검증함
- 2026 상반기는 반기 수치, 일부 회사는 공시 양식 차이로 항목이 비어 있음
- ‘전환일 이후 계약’은 공시의 세 번째 열(수정소급·공정가치법 외 ‘그 밖의 계약’) 기준이라, 회사에 따라 완전소급법 적용 계약이 포함됨
- 자동 추출은 금감원 잔액을 표 선택 기준으로 쓰므로, 금감원 통계와 공시 범위가 다른 회사(라이나)는 자동 선택이 불가능해 보정 파일로 처리
